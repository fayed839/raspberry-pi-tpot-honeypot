# Security, Ethics, and Privacy

## Purpose
This lab is intended exclusively for authorized defensive cybersecurity research and education.

## Public Repository Rules
Before publishing evidence:
- Remove passwords, tokens, API keys, and credentials.
- Remove personal information and unnecessary identifying data.
- Sanitize private/internal IP addresses where appropriate.
- Review screenshots for browser tabs, usernames, hostnames, Wi-Fi information, and other accidental disclosures.
- Do not publish live malicious payloads or material that creates unnecessary risk.
- Keep raw telemetry outside the public repository when it contains sensitive information.

## Lab Safety
- Isolate the honeypot from trusted devices and production systems.
- Restrict administrative access.
- Patch and monitor the underlying host.
- Assume files captured from hostile systems may be malicious.
- Maintain backups of important configuration/documentation.

## Responsible Documentation
The portfolio should demonstrate defensive analysis rather than exaggerating results. Statistics, attack techniques, and findings should be supported by actual lab evidence.
