# Sanitized Sample Data

Use this directory only for small, sanitized examples that help explain your analysis.

Good examples:
- Redacted JSON event
- Sanitized CSV summary
- Aggregated port counts
- Aggregated source-country/ASN statistics

Do not commit credentials, tokens, personal information, raw malware, unnecessary source identifiers, or large raw log exports.

When possible, use synthetic/redacted examples for demonstrating parsing or analysis code and keep the real raw telemetry in your private lab environment.
